# ✦ INTELLECT — новости искусственного интеллекта

Концепт-дизайн новостного медиа об ИИ: тёмная футуристичная лендинг-страница
с живой нейросетью на canvas, aurora-градиентами и glassmorphism-карточками.

## Запуск

Зависимостей нет — это один самодостаточный файл. Достаточно открыть
`index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Что внутри

- **Hero** — анимированная сеть частиц (canvas), реагирующая на курсор,
  плавающие aurora-блобы и стеклянные чипы со статистикой
- **Бегущая строка** — лента срочных новостей с паузой при наведении
- **Материал дня** — карточка с градиентной рамкой, орбитальной анимацией
  ядра и лёгким 3D-наклоном за курсором
- **Лента новостей** — 6 карточек с уникальной CSS-генерацией обложек
  (никаких картинок-файлов)
- **Тренды** — список с контурными номерами, заливающимися градиентом
- **Дайджест** — форма подписки с демо-состоянием успеха
- Плюс: прогресс-бар чтения, свечение за курсором, зерно-текстура,
  scroll-reveal анимации, мобильное меню

## Технологии

Чистые HTML + CSS + ванильный JS, ноль зависимостей.
Шрифты: Unbounded, Inter, JetBrains Mono (Google Fonts).
Поддержан `prefers-reduced-motion` и адаптив до мобильных экранов.
