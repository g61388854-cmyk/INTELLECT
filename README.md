# ✦ INTELLECT — новости искусственного интеллекта

Премиальный AI-портал в духе «цифровой библиотеки знаний будущего».
Палитра: графитовый чёрный, тёмно-серый, бордовый, золотой,
серебристо-белый. Без тяжёлых фреймворков — один самодостаточный файл.

## Запуск

Достаточно открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Что внутри

- **Экран приветствия** (первый визит): логотип, частицы собираются вокруг,
  световое кольцо, надпись «Добро пожаловать в пространство искусственного
  интеллекта» — затем плавный переход к сайту (флаг в localStorage)
- **Кастомный курсор — бумажный самолёт**: инерция, поворот по направлению
  движения, увеличение над активными элементами, световой импульс при клике,
  автоотключение на сенсорных устройствах
- **Книга знаний** — центральный 3D-объект в hero: золотое свечение и подъём
  при наведении; по клику раскрывается, между страниц появляется свет,
  взлетают частицы и цифровые символы, появляется надпись
  «Искусственный интеллект открывает новые знания», затем плавный переход
  к контенту
- **Telegram-интеграция**: кнопка в меню, пульсирующая плавающая кнопка
  в правом нижнем углу, информационный блок «Следите за развитием проекта»
  (канал: https://t.me/ai0090012)
- **Динамический фон**: нейросеть из частиц с соединительными линиями
  (canvas, золото/серебро/бордо) + дрейфующие цветовые пятна
- **Раскрывающийся блок «Как создавался проект»** с анимацией высоты
  и сменой иконки
- **Живой интерфейс**: подъём и увеличение карточек, свечение кнопок,
  scroll-reveal через Intersection Observer, бегущая строка, материал дня
  с орбитальным ядром и 3D-наклоном, тренды, форма подписки
- **Footer** с информацией об авторе проекта (Хучиев Рамзан Рустамович)
  и ссылкой на Telegram-канал

## Технологии

Чистые HTML + CSS + ванильный JS, ноль зависимостей.
Шрифты: Playfair Display, Inter, JetBrains Mono (Google Fonts).
Поддержан `prefers-reduced-motion`, адаптив до мобильных экранов,
высокая производительность (один canvas, CSS-анимации).
