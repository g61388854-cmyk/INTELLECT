# ✦ INTELLECT — интеллектуальный портал об искусственном интеллекте

Премиальная платформа об ИИ, технологиях, исследованиях и инновациях в духе
Apple / OpenAI / Linear. **Машинный разум. Человеческий взгляд.**

Минимализм, воздух, дорогая типографика, стеклянный 3D-куб, светлая и тёмная
темы. Чистые HTML + CSS + JS, без фреймворков и сборки — работает на GitHub
Pages как есть.

## Структура

```
index.html                 — главная: hero со стеклянным кубом, статистика,
                             факт дня, материал дня, категории, лента, подписка, о проекте
article.html?id=<slug>     — страница статьи: обложка, оглавление, цитаты,
                             блок фактов, источники, автор, похожие, Telegram
admin.html                 — SaaS-панель (код по умолчанию: intellect)
assets/theme.css           — дизайн-система: токены тем, стекло, навигация, типографика
assets/pages.css           — компоненты: hero+куб, карточки, плитки, статья, дашборд
assets/site.js             — хранилище контента, иконки, тема, общий интерфейс
assets/home.js             — логика главной (факт, лента, фильтр, плитки, куб)
assets/article.js          — статья + генерация оглавления + scroll-spy
assets/admin.js            — дашборд: новости, факты, категории, Telegram, настройки, статистика
data/articles.js           — статьи (seed) и категории (с иконками)
data/articles.generated.js — авто-новости (перезаписывает GitHub Actions)
data/facts.js              — база фактов (120+)
scripts/fetch-news.mjs     — ежедневный сбор RSS + анонс в Telegram
.github/workflows/update-news.yml — расписание автообновления
```

## Дизайн V2

- **Темы** — светлая (по умолчанию, как в макете) и тёмная; переключатель в
  навигации и в админке, выбор сохраняется. Анти-FOUC: тема ставится до отрисовки.
  Палитра: графит `#050505/#0A0A0A/#111111`, светлый фон `#FAFAF8/#F5F3EE/#FFFFFF`,
  акцент — матовое золото / шампань / янтарь.
- **Логотип** — новая геометрическая монограмма-куб (без звезды/робота/мозга).
- **Hero** — 100vh, слева заголовок и кнопки, справа премиальный **CSS 3D-куб**
  из стекла с тёплым золотым ядром и объёмным светом (без частиц и неона).
- **Фон** — тонкая сетка + мягкие световые пятна + виньетка (глубина без космоса).
- **Лента** — карточки в стиле App Store / Apple News: крупная обложка, компактный
  заголовок, дата и категория, описание в одну строку.
- **Категории** — 6 крупных плиток с минималистичными иконками и анимацией.
- **Статья** — ширина ~1000px, оглавление с подсветкой активного раздела,
  выделенные цитаты, блок «Знаете ли вы», карточки источников, автор, Telegram.
- **Анимации** — без тяжёлых библиотек: scroll-reveal, count-up, параллакс,
  плавные hover, вращение куба (всё с учётом `prefers-reduced-motion`).

## Админ-панель (SaaS)

`admin.html`, код по умолчанию `intellect` (меняется в «Настройках»). Разделы:
**Статистика** (KPI + графики по категориям и месяцам), **Новости** (создание,
редактирование, удаление, загрузка изображений с авто-ужатием, материал дня),
**Факт дня**, **Категории** (распределение), **Telegram** (токен/чат + памятка
по автопубликации), **Настройки** (тема, код доступа, экспорт, сброс правок).
Правки хранятся в `localStorage` браузера — это клиентская панель для наполнения,
код доступа не является серверной защитой.

## Автопубликация

`scripts/fetch-news.mjs` собирает RSS источников (OpenAI, Anthropic, Google
DeepMind, Meta AI, Microsoft, NVIDIA, Hugging Face, Stability AI), пишет
`data/articles.generated.js` и при наличии секретов `TELEGRAM_BOT_TOKEN` и
`TELEGRAM_CHAT_ID` (GitHub → Settings → Secrets) анонсирует новые статьи в
канал [t.me/ai0090012](https://t.me/ai0090012). Workflow `update-news.yml`
запускается ежедневно или вручную. Локально: `node scripts/fetch-news.mjs` (Node 18+).

## Запуск

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

Шрифты: Schibsted Grotesk + Inter (Google Fonts). Контентный слой (статьи,
факты, категории, автосбор) переиспользуется без изменений — V2 это рестайл
интерфейса, а не модели данных.
