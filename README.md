# ✦ INTELLECT — новости искусственного интеллекта

Концепт-дизайн новостного медиа об ИИ в стиле **liquid glass** («жидкое
стекло», как в iOS 26): полупрозрачные стеклянные панели с бликами по
кромке, преломление цветного фона, капли-линзы и плавающая навигация.

## Запуск

Зависимостей нет — это один самодостаточный файл. Достаточно открыть
`index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Что внутри

- **Liquid glass всюду** — единый рецепт стекла: `backdrop-filter: blur +
  saturate`, верхний блик кромки (inset-тень), глянец «свет сверху» и
  блик-волна, пробегающая по карточкам и кнопкам при наведении
- **Две темы** — тёмная и светлая, переключатель в навигации
  (☀︎/☾, выбор запоминается в localStorage)
- **Живой фон под стеклом** — дрейфующие цветные блобы + медленно
  вращающийся conic-градиент, которые панели преломляют и размывают
- **Капли-линзы** — стеклянные сферы с бликами, парящие в hero и дайджесте
- **Hero** — сеть частиц на canvas, тянущаяся линиями к курсору
  (палитра меняется вместе с темой)
- **Плавающая навигация-пилюля**, бегущая строка новостей, материал дня
  с орбитальной анимацией и 3D-наклоном, лента из 6 карточек с
  CSS-генерацией обложек, тренды-пилюли, форма подписки
- Детали: прогресс-бар чтения, свечение за курсором, зерно-текстура,
  scroll-reveal анимации, мобильное меню

## Технологии

Чистые HTML + CSS + ванильный JS, ноль зависимостей.
Шрифты: Unbounded, Inter, JetBrains Mono (Google Fonts).
Поддержан `prefers-reduced-motion` и адаптив до мобильных экранов.
