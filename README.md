# ✦ INTELLECT — портал новостей искусственного интеллекта

Полноценный информационный AI-портал: отдельные страницы статей, лента с
категориями, интерактивный «Факт дня», робот-помощник, счётчики статистики,
скрытая админ-панель и каркас ежедневной автопубликации. Премиальный стиль
«цифровой библиотеки знаний» — графит, бордо, золото, серебро.

Без фреймворков и сборки: чистые HTML + CSS + ванильный JS. Контент вынесен в
JS-модули, поэтому сайт работает и при открытии файла напрямую, и на GitHub Pages.

## Структура

```
index.html                 — главная: hero с роботом, статистика, факт дня,
                             материал дня, лента с категориями, Telegram, дайджест
article.html?id=<slug>     — страница отдельной статьи (+ похожие, кнопка назад)
admin.html                 — скрытая панель управления (код по умолчанию: intellect)
assets/theme.css           — дизайн-система (палитра, стекло, фон, курсор, навигация)
assets/pages.css           — компоненты страниц (робот, факт, лента, статья, админка)
assets/site.js             — хранилище контента + общий интерфейс + робот-персонаж
assets/home.js             — логика главной
assets/article.js          — отрисовка статьи
assets/admin.js            — CRUD статей и фактов
data/articles.js           — база статей (seed) и категории
data/articles.generated.js — авто-новости (перезаписывает GitHub Actions)
data/facts.js              — база фактов (120+)
scripts/fetch-news.mjs     — ежедневный сбор новостей из RSS + анонс в Telegram
.github/workflows/update-news.yml — расписание автообновления
```

## Что реализовано (по ТЗ)

1. **Отдельные страницы статей** — карточка ведёт на `article.html?id=<slug>`
   с заголовком, изображением/обложкой, датой, автором, полным текстом, блоком
   похожих материалов и кнопкой возврата.
2. **Автообновление новостей** — `scripts/fetch-news.mjs` собирает RSS восьми
   источников (OpenAI, Anthropic, Google DeepMind, Meta AI, Microsoft, NVIDIA,
   Hugging Face, Stability AI), формирует карточки и пишет `articles.generated.js`;
   GitHub Actions запускает скрипт ежедневно.
3. **Факт дня** — 120+ фактов, кнопка «Узнать новый факт», анимация перемешивания
   колоды и робота, выдача случайного факта без повторов недавних.
4. **Робот-персонаж** — анимированный SVG: приветствует, машет рукой, следит
   глазами за курсором, участвует в выдаче фактов.
5. **Книга знаний удалена** — место занято лентой, фактом дня и роботом.
6. **Лента публикаций** — карточки с обложкой, заголовком, датой, категорией,
   описанием; открытие полной статьи по клику; кнопка «Показать ещё».
7. **Категории** — ИИ, Нейросети, Робототехника, Наука, Технологии, Стартапы,
   Исследования; фильтр-пилюли над лентой.
8. **Telegram** — кнопка в меню, плавающая пульсирующая кнопка на всех страницах,
   блок «Следите за развитием проекта», авто-анонс новых статей в канал.
9. **Статистика** — счётчики (публикации, факты, категории, дни проекта),
   анимированно растут при появлении на экране.
10. **Админ-панель** (`admin.html`) — публикация, редактирование, удаление статей,
    загрузка изображений (с авто-ужатием), управление фактами.

## Хранение контента

`assets/site.js` объединяет три источника статей: ручные (из админки), авто-собранные
(`articles.generated.js`) и базовые (`articles.js`). Правки и удаления админки
хранятся в `localStorage` браузера и сразу видны на сайте. Это клиентская
демонстрационная панель — код доступа не является серверной защитой.

## Автопубликация: настройка

1. В репозитории добавьте секреты (Settings → Secrets → Actions):
   - `TELEGRAM_BOT_TOKEN` — токен бота (через @BotFather), бот — администратор канала;
   - `TELEGRAM_CHAT_ID` — `@ai0090012` или числовой id.
2. Workflow `update-news.yml` запускается по расписанию (06:00 UTC) или вручную
   (Actions → Run workflow). Скрипт обновит `articles.generated.js` и пришлёт
   анонсы новых статей в канал.
3. Локальный прогон: `node scripts/fetch-news.mjs` (Node 18+, без зависимостей).

## Запуск локально

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

Шрифты: Playfair Display, Inter, JetBrains Mono (Google Fonts).
Поддержаны `prefers-reduced-motion`, адаптив, кастомный курсор-самолёт
(отключается на сенсорных экранах).
